This dashboard reads real attendance records from the deployed smart contract for this prototype's known demo students. Approving a record calls verifyAttendance() on-chain, which marks it Approved and credits 10 points — so approving requires connecting the lecturer/admin wallet via MetaMask; nothing here is simulated. Because the contract has no built-in way to list "every student," this prototype only shows the fixed set of demo students registered for testing, not an open student directory.
